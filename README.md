# Mush Cafe Website

## Project title
Mush Cafe - Professional Café Website

## Project purpose
This project was developed as part of the WEDES020 Web Development Introduction Part 2 assignment. The purpose of the website is to promote Mush Cafe as a modern local café and provide clear information about the menu, story, contact details, and enquiry form.

## Website overview
The website includes five main pages:
- Home page
- Menu page
- About page
- Contact page
- Enquiry page

The design keeps the Mush Cafe identity while improving the overall layout, typography, colour palette, and responsiveness to create a more professional user experience.

## Technologies used
- HTML5
- CSS3
- Responsive web design
- Flexbox
- CSS Grid
- Media queries
- Pseudo-classes and hover/focus states
- Existing project images

## Pages included
1. `index.html` - hero section, service highlights, call to action, and brand overview.
2. `menu.html` - food and drink menu cards with pricing.
3. `about.html` - story, mission, and vision sections.
4. `contact.html` - business information and opening hours.
5. `enquiry.html` - enquiry form with proper labels and form controls.

## Design features
- Professional café colour palette
- Strong visual hierarchy and spacing
- Styled buttons, cards, hero content, and footer
- Modern hover and focus states
- Responsive navigation for desktop, tablet, and mobile
- Optimised photos using responsive image handling
- Semantic HTML5 layout using header, nav, main, section, article, and footer

## Responsive design
The website uses CSS Grid and Flexbox for layout, with media queries to adjust the design for:
- desktop screens
- tablet screens
- mobile screens

The layout ensures no horizontal scrolling, improved readability, and consistent spacing on smaller devices.

## Testing
The website was reviewed to confirm:
- all pages are linked to the same external stylesheet
- navigation is consistent across the site
- the markup uses semantic elements
- forms include labels and accessible controls
- images are stored in the project and referenced correctly
- responsive layouts adapt at smaller screen sizes
